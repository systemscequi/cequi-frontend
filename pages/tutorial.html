🎓 Tutorial — Sistema CEQUI

Guia completo de uso do sistema de controle de produtividade

1 Registrar Dias Trabalhados ⚠️ ESSENCIAL

Sem registrar os dias trabalhados, o cálculo de produtividade ficará incorreto. Faça isso todo mês.

  1. Acesse Controle de Presença pelo menu
  2. Selecione o servidor no topo da página
  3. Navegue até o mês desejado
  4. Clique em cada dia para alternar entre os status:
✓ Trabalhado ⚠ Ausência justificada 🔵 Dispensa de ponto 🏦 Banco de horas 🌴 Férias

💡 Use o botão "📋 Registrar Mês" para marcar todos os dias úteis de uma vez.

2 Cadastrar Produtos

Cada produto representa um projeto ou demanda. O fluxo é dividido em etapas.

  1. Etapa 1 — Dados do Produto: Informe o nome do produto. O código é gerado automaticamente. Defina data de início e fim — ambas devem estar no mesmo mês.
  2. Etapa 2 — Atividades: Adicione as atividades padrão do produto (ver passo 3).
  3. Etapa 3 — Revisão: Confira tudo e salve. O produto será criado com status Em Andamento.

💡 Você também pode editar um produto depois pela Lista de Produtos.

3 Adicionar Atividades Padrão

Cada produto deve ter ao menos uma atividade. As atividades padrão vêm de uma biblioteca por categoria.

  1. Na tela Nova Atividade, selecione o produto
  2. Escolha a categoria (DGSPI, EAC, EPCI, EEME, ECA, ETP)
  3. Selecione a atividade padrão no dropdown — o tooltip mostra o texto completo
  4. Defina a complexidade: 0.5 · 1 · 1.5
  5. Os pontos são calculados automaticamente: Peso × Complexidade
  6. Adicione uma observação se necessário e clique em Adicionar

💡 Para editar uma atividade já adicionada, clique no ✏️ ao lado dela na lista.

4 Atividades Livres

Quando nenhuma atividade padrão se encaixa, você pode criar uma atividade livre diretamente.

  1. Acesse Cadastro de Atividades → aba 🆓 Atividades Livres
  2. Preencha descrição, categoria, complexidade e peso (2 a 20, apenas pares)
  3. O código é gerado automaticamente no padrão LIVRE01, LIVRE02...
  4. A atividade fica disponível nos seletores de nova atividade

💡 Com o botão ⭐ Tornar Padrão, você pode promover a atividade para a biblioteca oficial — o admin define o código e categoria definitivos.

5 Status dos Produtos

🔄 Em Andamento ✅ Finalizado ❌ Não Concluído
  • Em Andamento: status inicial de todo produto cadastrado
  • Finalizado: produto concluído — entra no cálculo de produtividade. Pode ser marcado manualmente na edição do produto
  • Não Concluído: atribuído automaticamente quando o mês vira sem o produto ser finalizado. Pode ser alterado manualmente apenas pelo admin

⚠️ Apenas produtos Finalizados entram no cálculo de produtividade. Produtos em andamento são contabilizados na pontuação total.

6 Lista de Produtos

Visualize, filtre e gerencie todos os seus produtos em um só lugar.

  • Filtre por mês/ano — mostra produtos cujo início é naquele mês
  • Filtre por status (Em Andamento / Finalizado / Não Concluído)
  • Clique em ✏️ Editar para alterar dados do produto, incluindo status
  • A coluna Duração mostra os dias corridos entre início e fim
  • Clique em ➕ Adicionar Atividade para incluir mais atividades no produto

7 Dashboard

Visão rápida do mês selecionado. Use o seletor de servidor no topo para alternar entre colaboradores (admin).

  • Pontos Finalizados: soma dos pontos de produtos finalizados no mês
  • Produtividade Média: pontos finalizados ÷ dias trabalhados
  • Desempenho Relativo: comparativo em % com a média da equipe no mesmo mês
  • Gauge de Presença: taxa de dias trabalhados vs dias úteis
  • A lista de produtos mostra todos os do mês, com atividades expansíveis

8 Relatórios

Relatório Individual — selecione servidor e período. Mostra:

  • KPIs: Pontos Finalizados, Produtividade Média Diária, Pontuação Total, Total de Produtos, Duração Média
  • Card unificado de status (Em Andamento / Finalizados / Não Concluídos)
  • Tabela de produtos com atividades expansíveis
  • Exportação em Excel (.xlsx) com abas "Produtos" e "Atividades"

Relatório da Equipe — mostra todos os servidores no período. Inclui:

  • KPIs: Total Servidores, Total Produtos, Média Geral, Média por Área, Pontuação média equipe/dia, Duração Média
  • Tabela com Total Prod., Dias Trab., Finalizados, Não Concluídos, Duração Média, Pontos, Média/Dia, Desempenho Relativo
  • Exportação em Excel (.xlsx) com todos os indicadores

9 Visão da Equipe 🔒 Admin

Comparativo de produtividade de todos os servidores filtrado por mês.

  • Filtre por mês/ano — usa a regra de início do produto
  • KPIs: Total Servidores, Produtos do Mês (And/Fin/N.C.), Média de Produtividade, Pontuação média equipe/dia, Duração Média dos Produtos
  • Tabela com Total Produtos, Dias Trabalhados, Pontos, Média Diária e Desempenho Relativo (% vs média da equipe)
  • Clique em um servidor para ir direto ao dashboard dele

📐 Como os Cálculos Funcionam

Pontos do Produto
Σ (Peso da Atividade × Complexidade)
Produtividade Média Diária
Pontos Finalizados ÷ Dias Trabalhados
Pontuação média equipe/dia
Σ(média diária individual) ÷ servidores com registro
Duração Média dos Produtos
Σ(dias corridos de produtos finalizados) ÷ total finalizados
Desempenho Relativo
(Pontos Servidor − Média Equipe) ÷ Média Equipe × 100%
Taxa de Presença
(Dias Trabalhados ÷ Dias Úteis) × 100%
🗓️ Regra do Mês: Todos os filtros por mês usam a data de início do produto. Um produto de janeiro só aparece em janeiro, independente de quando foi finalizado.

📊 Benchmark: A meta de produtividade é de 8 pts/dia para todas as áreas. Indicadores ficam verdes acima de 8, amarelos entre 6.4 e 8, e vermelhos abaixo de 6.4.

💡 Dicas Importantes

📅 Registre a presença todo mês

É o dado mais importante. Sem ele, a produtividade não é calculada.

✅ Finalize os produtos

Apenas produtos finalizados entram no cálculo de produtividade.

📆 Mesmo mês

Data de início e fim do produto devem estar no mesmo mês.

🆓 Use atividades livres

Quando nenhuma atividade padrão se encaixa, crie uma livre e peça para torná-la padrão depois.

💾 Faça backup regularmente

Configurações → Exportar Backup. Guarde o arquivo em local seguro.

📊 Acompanhe a equipe

A Visão da Equipe (admin) mostra o Desempenho Relativo de cada servidor vs a média.

📥 Export Excel

Os relatórios exportam em .xlsx com abas separadas por tipo de dado.

🔒 Sessão automática

A sessão expira em 8 horas e é apagada ao fechar o navegador por segurança.
